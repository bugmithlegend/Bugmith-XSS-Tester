# Bugmith-XSS-Tester
Automate discovery &amp; exploitation of direct XSS vulnerabilities manually, automated manual hunting for XSS.

## Installination steps
1. Copy JS code in the file on the github
2. Create a bookmark in the broswer
3. Paste the JS code in the URL of the bookmark
4. Start exploiting pages along with DOM Invader detecting sinks & sources, manually hunting
